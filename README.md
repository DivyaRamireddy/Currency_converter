# 💱 Currency Converter (Python)

A simple **Currency Converter** program written in Python.  
It takes an amount in **INR (Indian Rupees)** and converts it into other currencies like **USD, EUR, and JPY** using fixed conversion rates.  

---

## 🚀 Features
- Convert INR to multiple currencies (USD, EUR, JPY).
- Easy to use and beginner-friendly.
- No external libraries required.
- Runs on any Python environment.

---

## 🛠️ Technologies Used
- **Python 3**
